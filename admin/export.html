Data Export Tool

Reads your existing Dashboard data exactly as it is right now and packages it into one downloadable file, so it can later be verified and migrated to permanent online storage. Nothing on this page writes, changes, or deletes anything.

This tool is 100% read-only. It only reads from:
  • localStorage["iraivaAdmin.songs.v1"]
  • localStorage["iraivaAdmin.albums.v1"]
  • IndexedDB "iraivaAudioDB" (store audioFiles)
It never calls .removeItem(), .clear(), .delete(), or any Supabase/network endpoint. Your original browser data is left exactly as it is, whether or not you run an export.

Run Export

Open this page on the same browser and device/profile where you actually use the live Dashboard to add/edit songs and albums — that's the only place this real data exists. Then click below.
